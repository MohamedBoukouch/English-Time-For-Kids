## <img src="https://api.iconify.design/mdi/teddy-bear.svg?color=%23FF7043" width="24" style="vertical-align:middle"/> What Is It?

**Learn English For Kids** is a lightweight educational app that helps young children discover their first English words in a fun, visual, and completely safe environment.

There's no sign-up, no internet requirement, and no complicated menus — a child opens the app, taps a colorful category, hears the word, sees the picture, and learns. That's it.

The app is built with **Flutter** on the frontend and uses **GetX** for state management. There is **no backend at all** — every word, sound, and image lives locally inside the app, which is exactly why it works perfectly offline, anywhere, anytime.

## <img src="https://api.iconify.design/mdi/sitemap.svg?color=%23FF7043" width="24" style="vertical-align:middle"/> Architecture — UI-Only, Fully Local

Unlike a typical client-server app, Learn English For Kids has **no backend and no API calls**. Everything the app needs ships inside the app itself:

1. **Flutter UI** — Screens, widgets, and navigation the child interacts with directly.
2. **GetX Controllers** — Handle app state, current category/word, activity progress, and audio playback triggers.
3. **Local Assets** — Words, images, categories, and audio pronunciation files bundled locally inside the app.
4. **Local Storage** — Any saved progress or settings are kept on-device only — nothing is ever sent to a server.

This "local-first" design is exactly why the app works perfectly offline and needs no account, login, or internet connection.
